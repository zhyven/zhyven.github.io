各目录的作用：

目录/文件 作用
_config.yml 整个博客的控制中心，标题、主题、URL 等都在这里配置
source/_posts/ 存放你的 Markdown 博客文章
themes/ 存放主题，可从网上下载并切换
scaffolds/ 新建文章/页面时的初始模板
public/ Hexo 生成的静态文件（不需要手动修改）

hexo 命令

命令 作用
hexo g 将 Markdown 编译为静态文件
hexo s 启动本地预览服务器
hexo cl 清除已生成的静态文件
hexo s -p 5000 指定端口启动
hexo d 部署

Hexo 文章

格式

在 Hexo 里，一篇文章通常由两部分组成：

  1. 头部配置
  2. 正文内容

中间那一段被 --- 包起来的区域，就是 front-matter。Hexo 会根据这些信息决定：

  • 文章标题是什么
  • 发布时间是什么
  • 属于哪些标签
  • 属于哪个分类
  • 是否发布
  • 链接怎么生成

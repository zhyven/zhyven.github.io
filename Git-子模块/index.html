Git 子模块

发表于2026-06-03|更新于2026-06-03|Git
|浏览量:

子模块允许你将一个 Git 仓库作为另一个 Git 仓库的子目录。它能让你将另一个仓库克隆到自己的项目中，同时还保持提交的独立。

核心

  • 主仓库不保存子模块的实际文件，只保存一个指向子模块特定提交的引用（commit SHA-1）。

  • 子模块是独立的仓库，可以有自己的分支、提交、远程仓库。

  • 当克隆主仓库时，需要额外操作才能拉取子模块的内容。

添加子模块

执行后会在主仓库根目录生成一个 .gitmodules 文件，记录子模块信息。

克隆带有子模块的仓库

git submodule update --init 等价于 git submodule init 和 git submodule update。

如果还要初始化、抓取并检出任何嵌套的子模块， 请使用简明的 git submodule update --init --recursive。

更新子模块到最新提交

主仓库记录的是子模块的固定提交，而不是分支。更新子模块后，必须在主仓库中提交新的引用。
